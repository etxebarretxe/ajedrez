    🗂️ Organizar páginas

    Reordena (arrastrando), rota o elimina páginas.

    🗜️ Comprimir PDF

    Reduce el tamaño del archivo.

    Arrastra aquí un PDF o

    La compresión por imagen rasteriza las páginas: reduce mucho los PDF escaneados, pero el texto deja de ser seleccionable. Marca la casilla de arriba si quieres conservar el texto.

    ✏️ Editar (superponer)

    Añade texto, formas o tapa zonas encima del PDF. No modifica el texto original.

    Arrastra aquí un PDF o

    Consejo: haz doble clic en una caja de texto para escribir. Arrastra desde el borde inferior derecho para redimensionar. Los elementos son por página.
