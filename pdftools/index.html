    🗜️ Comprimir PDF

    Reduce el tamaño del archivo.

    Arrastra aquí un PDF o

    La compresión por imagen rasteriza las páginas: reduce mucho los PDF escaneados, pero el texto deja de ser seleccionable. Marca la casilla de arriba si quieres conservar el texto.

    ✏️ Editar (superponer)

    Añade texto, formas o tapa zonas encima del PDF. No modifica el texto original.

    Arrastra aquí un PDF o

    Consejo: arrastra una caja para moverla. Haz doble clic para escribir dentro. Arrastra desde el borde inferior derecho para redimensionar. Los elementos son por página.

    🖼️ Imagen a PDF

    Convierte una o varias imágenes (JPG, PNG, WEBP...) en un PDF. Arrastra para reordenarlas.

    Arrastra aquí tus imágenes o

      ¿El PDF resultante pesa mucho? Puedes reducirlo después con la herramienta "Comprimir".

      🛡️ Marca de agua

      Para enviar documentación sensible (DNI, nóminas...): añade una marca diagonal repetida con destinatario y fecha. El resultado se aplana, así que la marca no se puede quitar con un editor de PDF.

        Vista previa (primera página)
